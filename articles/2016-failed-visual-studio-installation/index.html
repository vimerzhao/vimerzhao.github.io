记一次失败的Visual Stdio安装经历

赵裕(vimerzhao)
2016-02-04 (最后修改: 2026-07-31)
系统与工具
本文约 600 字，阅读需 2 分钟。

write by ai

原文：CSDN 链接 `n121寒假打算从C++开始认真补一补编程，加之又新换了一台电脑，于是乎一个想法油然而生，开始学习VS;因为打算学习多种语言和一些应用开发，而用VC++6.0这种所谓经典的IDE其实可能有点赶不上时代了（这个IDE似乎只剩下学校教学之用了）。加上年轻，喜欢做点表面文本开始风风火火装起了Visual Stdio 2015社区版（因为考虑到win10，可能新版本兼容性更好）

由于网络和自己平时阅历也不是太多，连下载地址都花了点时间才找到

这种东西必须官网下啊，毕竟还有免费版！

然后安装还是很熟悉的

接下来就是出问题的根源了，个人爱好，反是有的功能必须都装上，用不用是另外一回事

41GB，真是一身冷汗！！！

还是英勇无畏的装下去了

真不是催的，装起来可真慢（还有一部分原因是我是在线安装那种）

然而悲剧终究还是发生了，天真的我之前选的功能里好像有一些被墙调不能下了，于是呜呼哀哉

垂死挣扎

然而，年轻的我以失败告终

并发现C盘莫名多了，此时心里的阴影面积已经无法估计，怒删所有（其实有的已经造成永久性伤害了）呜呜

只留下残垣断壁与当时装逼的痕迹

看到Android就想起上次在学校弄ADT，还是太年轻。

不过话又说回来，学习只需要用满足需求的工具就够了，过于强调工具反而会使自己忘记了重心。就像学编程只学到了语法而忽视了核心内涵一样。

后来我装了codeblocks，够用，不哭！！！！
